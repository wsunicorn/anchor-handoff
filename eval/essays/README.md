# Bài tự luận cho tiêu chí thoát G5

10 bài viết thật (do người làm viết như sinh viên, có lỗi cố ý) về 3 tài liệu mẫu trong `docs/samples`.
Chạy `bash scripts/grade-eval.sh` → in bảng: mỗi bài bao nhiêu nhận xét hiển thị / bị ẩn, mọi nhận xét
hiển thị có `citation` phân giải được không, có nhận xét mức 3 nào lọt ra không.
